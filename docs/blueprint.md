# **App Name**: PetMets Connect

## Core Features:

- Home Page: Introducing PetMets with calls to action.
- "How It Works" Page: Explaining the pet connection process.
- About Us Page: Sharing the PetMets mission and vision.
- User Authentication: Basic authentication using Firebase.
- Dashboard Placeholder: Simple logged-in user dashboard.
- AI Profile Draft: Automated profile setup: tool uses the pet owner's registration data and profile image to construct a draft 'about me' section for their and their pet's profiles. Requires manual approval to publish.

## Style Guidelines:

- A warm orange (#FF8C00) to evoke feelings of friendliness, energy, and connection.
- A light orange (#FFF3E0) to create a comforting and inviting backdrop.
- A complementary blue (#3d605a) to provide contrast and highlight key actions.
- 'Belleza' (sans-serif) for titles, to convey a sense of artful connection. Body Font: 'Alegreya' (serif) to convey a feeling of modern elegance and intellect.
- Use rounded, friendly icons related to pets, friendship, and community.  A key element of this app is images, so image thumbnails must be designed to be prominent.
- Clean and simple layouts with plenty of white space to enhance readability and focus.
- Subtle animations to provide feedback on user interactions.
